長時間稼働の工夫① 裏で走らせる

たとえるならコース設計フルマラソンを完走するための道のり作り
  • -p（--print）: 非対話で結果だけ受け取る実行方式 ✅
  • run_in_background: true: 長時間プロセスを裏で走らせつつ作業継続 ✅
  • /tasksで一覧・停止ができる ✅

出典を見る → code.claude.com/docs/en/headless

長時間稼働①19
ClaudeCodeチャンネルClaude Code を学ぶ
05

長時間稼働の工夫② 止まらせない設計

  • バックグラウンドのサブエージェント・ワークフローは、最終出力の一部として結果を待ってもらえる ✅
  • v2.1.182以降は既定で最大10分のタイムアウトが付き、詰まったタスクが無限に居座らない ✅
  • 大きなタスクはサブエージェントに切り出し、本体とは別のコンテキストで処理する ✅

出典を見る → code.claude.com/docs/en/headless

トークン節約の工夫① こまめに整える

たとえるならペース配分給水のたびに息を整え、オーバーペースを防ぐ
  • /clear: 無関係な過去のやり取りを送り直さない ✅
  • /compact: 席を外す前に。キャッシュが生きているうちの要約は安い ✅
  • /rewind: 直近の不要なターンだけを切り捨てる。compactより低コスト ✅

出典を見る → claude.com/blog/maximizing-the-value-of-your-claude-code-sessions

ClaudeCodeチャンネルClaude Code を学ぶ

トークン節約の工夫② 積む前に削る

  • /context: セッション開始時に1回。CLAUDE.md・MCPツール定義など何が読み込まれているか確認する ✅
  • /mcp: 使わないMCPサーバーの起動を止める ✅
  • /model /effortはセッション開始時に決め、途中で変えない（変更するとキャッシュが失効しコスト増）✅
